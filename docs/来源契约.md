# 来源契约

S3兼容子集：GET /research?versions=&max-keys=2&encoding-type=url，响应为S3 ListVersionsResult XML。Version和DeleteMarker按键及各版从新到旧排列。IsTruncated=true时同时给NextKeyMarker、NextVersionIdMarker，续页需将两者作为key-marker与version-id-marker。encoding-type=url时XML中的键与NextKeyMarker使用UTF-8百分号编码，versionId本身按查询参数编码。
GET /research/<编码键>?versionId=<版号>固定读取某版。省略版号读取当前；当前为删除标记时返回404与x-amz-delete-marker=true。明确读取删除标记返回405；永久清理的版返回404与NoSuchVersion。删除标记不是零长对象，不能替代原件。
响应给x-amz-version-id、完整对象x-amz-checksum-sha256（base64）、ETag及字节总长。Range: bytes=start-end使用闭区间，正常返回206及Content-Range；超界416，ignore_range控制可使来源返回200整件。此合成来源允许不同对象版本ETag相同，不承诺ETag是整文件摘要。
阶段0有项目 A/练习 数据.bin 的v+2、v+1及独立附件；阶段1新增delete-3；阶段2永久清理v+1，v+2仍可明确取回。fixtures/research-requests.json是两次独立实验的资料引用，版本与研究引用均为合成数据。

演练控制：POST /__control 接收JSON stage及上述控制项，GET /__log显示请求观测；它们供资料源演练与来源测试使用，不属于业务资料获取接口，不得用其直接生成采集结果。每次启动是独立状态。GET /health仅检查服务可用性。
